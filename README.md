# Rwanda Market Management System (RMMS)

  A full-stack web application for managing Rwanda's formal and informal markets.

  ## Features
  - National Dashboard with KPI cards
  - Market Management (8 pre-seeded markets)
  - Slot Management
  - Vendor Registry
  - Payment Tracking
  - Expense Tracking
  - Notification Engine (simulated SMS)

  ## Stack
  - **Frontend**: React + Vite
  - **Backend**: Node.js + Express 5
  - **Database**: PostgreSQL + Drizzle ORM
  - **Auth**: JWT
